# Integer Linear Programming with GLPK/AMPL

This example models a **production scheduling problem for a film recording**. The goal is to determine the order in which scenes should be recorded so that every scene is assigned to exactly one recording day, while minimizing the actors' waiting costs.

## Problem context

A production has:

- A set of scenes that must each be recorded once.
- A set of actors, each participating in a subset of the scenes.
- A daily waiting cost for every actor.
- One scene scheduled per recording day.

An actor incurs waiting time when they must remain available before their first recording day, after their last recording day, or between recording days in which they participate. The model uses these periods to calculate the total waiting cost of the schedule.

The scheduling decision is represented by binary variables indicating whether a scene is recorded on a particular day. Additional binary variables identify the pre-recording and post-recording periods for each actor. The objective is to minimize:

```text
sum(actor waiting days × actor daily waiting cost)
```

## Model

The AMPL model is defined in [`pli.mod`](pli.mod). It includes:

- Scene and actor sets.
- The actor/scene participation matrix `T`.
- Daily waiting costs `c`.
- Binary scene-assignment variables.
- Constraints ensuring that every scene and every recording day are used exactly once.
- Constraints that calculate each actor's recording, pre-recording, and post-recording periods.
- An objective function minimizing the total waiting cost.

## Running the model

The model is intended to be solved with GLPK's `glpsol` command and a separate AMPL data file. The command shown in the model is:

```bash
glpsol --model pli.mod --data e0806.dat --output pli.opt --wcpxlp pli.lp
```

The data file must define the parameters required by `pli.mod`, including `n`, `m`, `T`, and `c`.

After solving, the model writes the selected scene order and the objective value to `saida.txt`.

## Files

- [`pli.mod`](pli.mod): AMPL mixed-integer programming model.
- `e0806.dat`: Expected input data file; provide this separately if it is not included in the repository.
- `saida.txt`: Output file generated by the model.
